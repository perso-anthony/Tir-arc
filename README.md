# Carnet de tir

Appli de score de tir à l'arc : saisie des flèches, volées, séances et statistiques. Fonctionne hors ligne une fois installée depuis Chrome (PWA).

Adresse : https://perso-anthony.github.io/Tir-arc/

Les séances sont enregistrées dans le navigateur du téléphone. Historique > Sauvegarde permet d'exporter et d'importer un fichier JSON.

À chaque modification de `index.html`, augmenter le numéro de `CACHE` dans `sw.js` pour que les téléphones récupèrent la nouvelle version.
